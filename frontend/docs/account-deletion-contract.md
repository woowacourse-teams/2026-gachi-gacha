# 웹 회원 탈퇴 계약과 검증

2026-11-04 `backend-dev` (`9390bc81`)와 `main` (`173b83ab`)의 웹 컨트롤러 및 개발·운영 서버의 OPTIONS 응답을 확인했다. 이 문서는 웹 마이페이지와 공개 `/account-deletion` 페이지에 적용하며, 네이티브 앱 전용 API 계약을 정의하지 않는다. 모바일 반응형 화면도 같은 웹 계약을 사용한다.

## 요청과 완료 조건

| 목적                   | 웹 API                                    | 완료 조건                                                                                               |
| ---------------------- | ----------------------------------------- | ------------------------------------------------------------------------------------------------------- |
| 내 정보 조회·수정      | `GET` / `PATCH /api/v1/members/me`        | 기존 계약 유지. DELETE 경로가 아니다.                                                                   |
| 탈퇴 요청              | `DELETE /api/v1/oauth/withdraw`           | 인증된 요청의 성공 응답 `C003` 확인 후에만 토큰과 세션 상태를 정리한다.                                 |
| Apple 재인증 주소 발급 | `GET /api/v1/oauth/withdraw-url`          | 탈퇴 요청의 `AUE03` 응답일 때만 호출한다. `C000`과 HTTPS `appleid.apple.com` 주소를 검증한 뒤 이동한다. |
| Apple 재인증 반환      | `POST /api/v1/oauth/withdraw/apple`       | Apple이 백엔드에 반환한다. 프런트가 직접 호출하지 않는다.                                               |
| 웹 완료 화면           | `/oauth/withdraw-callback#result=success` | 성공일 때만 토큰을 정리한다. 오류 콜백은 실패를 안내한다.                                               |

마이페이지와 공개 탈퇴 페이지는 `AuthSessionContext.deleteAccount()`를 공유한다. 서버 발급 URL로 이동하기 전에는 인증 토큰을 유지한다. 405/500 및 재인증 주소 검증 오류에서는 확인 문구와 세션을 보존하고 사용자에게 오류를 알린다. 401 인증 만료는 공통 인증 처리 정책을 따른다. 405/500에 다른 URL이나 HTTP 메서드로 자동 우회하는 삭제 재시도는 추가하지 않는다.

## 회귀 검증

- API 주소는 컨트롤러와 실제 서버의 허용 메서드를 먼저 대조한다. 구현 상수와 MSW를 동시에 바꾸는 것만으로 계약 검증을 대신할 수 없다.
- 마이페이지·공개 페이지의 탈퇴 성공과 인증 헤더, 성공 이후 토큰 정리를 검증한다.
- 405/500 실패에서 입력·토큰이 유지되고 재인증이나 다른 삭제 주소로 우회하지 않는지 검증한다.
- Apple AUE03 → 재인증 주소 발급 → 주소 검증 및 이동, 발급 실패, 콜백 성공·실패를 검증한다.
- Storybook 회원 탈퇴 mock도 웹 계약과 일치시킨다. 내 정보 GET/PATCH mock은 `/members/me`를 유지한다.
- 배포 확인은 OPTIONS와 공개 페이지 GET으로 수행할 수 있지만, 이것만으로 실제 회원 삭제나 Apple 제공자 왕복 성공을 보장하지 않는다.
- 실제 탈퇴 검증은 별도로 승인된 폐기 가능한 테스트 계정만 사용한다. 사용자 계정으로 DELETE 요청을 보내거나 인증 토큰을 로그에 남기지 않는다.

## 변경 이력

- #593에서 `/members/me`와 `/oauth/withdraw/apple/url`로 변경했으나 실제 웹 계약과 불일치했다.
- #624에서 웹 OAuth 경로를 복구하고 성공·실패 회귀 검증을 보강한다. 백엔드·네이티브 앱 코드는 변경하지 않는다.
