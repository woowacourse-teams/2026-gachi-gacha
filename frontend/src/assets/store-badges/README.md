# 공식 스토어 다운로드 배지

사용자가 제공한 공식 한국어 SVG를 수정하지 않고 복사했다. 프로젝트 최상위 `frontend/`의 제공 원본은 그대로 유지한다.

- `app-store-ko.svg`: `Download_on_the_App_Store_Badge_KR_RGB_blk_100317.svg`
- `google-play-ko.svg`: `GetItOnGooglePlay_Badge_Web_color_Korean.svg`

이벤트 설치 안내 팝업에서 사용한다. 로고·색상·문구·비율을 변경하거나 별도 아이콘으로 재작성하지 않는다. App Store 배지를 먼저 배치하고 두 배지의 표시 높이를 맞춘다. 작은 화면은 40px, 화면 폭 360px부터 44px, 375px부터 46px, 412px부터 48px, 600px부터 56px로 키운다. 폭은 원본 비율에 따른다. 배지를 같은 폭으로 늘리거나 자르지 않는다.

배지 사이 여백은 16px(화면 폭 360px부터 20px), 위아래는 16px, 좌우는 팝업 패딩으로 확보해 표시 높이의 1/4 이상을 유지한다. 320px 화면까지 가로 배치하고 더 좁은 공간에서는 잘리거나 축소되지 않게 줄바꿈한다. 설치 안내는 본문과 같은 서체·색상으로 배지 위에, 배지는 팝업의 마지막 영역에 배치한다.

- [Apple 마케팅 지침](https://developer.apple.com/app-store/marketing/guidelines/)
- [Google Play 공식 배지 지침](https://partnermarketinghub.withgoogle.com/brands/google-play/google-play/lockups-icons-badges/)

설치 링크는 해당 앱의 공개 스토어 페이지이며 자동 이동하지 않는다. 배지 사용은 해당 플랫폼의 이벤트 후원이나 제휴를 뜻하지 않는다.
