# 현장 홍보용 가치가챠 프리뷰

정식 v0.1.0 구현과 별도로 사용자에게 디자인과 이용 흐름을 보여 주는 임시 데모다.
이 데모를 정식 v0.1.0 기능 완료 또는 실제 재고 서비스로 취급하지 않는다.
정식 `package.json` 버전과 Git 태그는 이 임시 브랜치에서 변경하지 않는다.
PR에는 정식 릴리스와 구분되는 홍보용 프리뷰임을 명시하고 버전 변경 여부를 검토한다.

## 격리 방식

- 학습 브랜치: `feature/89-search-results`, 보존 기준: `827e075`.
- 데모 브랜치: `demo/promo-preview`, 기반: `frontend-dev`.
- 변경은 `src/demo/`와 Webpack의 opt-in 진입점, DEV 빌드 명령에 한정한다.
- 기존 `src/main.tsx`, `src/App.tsx`, 백엔드, PROD 워크플로우, Nginx는 수정하지 않는다.
- 데모 빌드의 `/demo`와 하위 경로만 프리뷰를 실행한다.
- 데모 빌드라도 `/demo` 밖의 주소에서는 기존 `main.tsx`를 실행한다.
- 일반 빌드는 기존 진입점을 사용하며 데모 모듈과 사진을 번들에 넣지 않는다.

## 실행

기존 프로젝트와 동일한 Node/pnpm 버전과 로컬 환경 설정을 사용한다.

```bash
pnpm install --frozen-lockfile
pnpm dev --env demo --port 3011
```

`http://localhost:3011/demo`에서 확인한다.

```bash
pnpm build --env demo
pnpm run check
pnpm run build-storybook
```

- `pnpm build --env demo`: 데모와 기존 앱을 경로별로 실행하는 DEV 배포 산출물.
- `pnpm build`: 데모를 제외한 기존 앱의 일반 산출물.
- 배포는 `frontend-dev` 대상 PR 검토·머지 후 기존 Actions를 이용한다.
- 제공 주소는 `https://dev.gachigacha.kro.kr/demo`이며, 기존 B2C 루트와 B2B 주소는 유지한다.
- 자동 머지, 강제 푸시, Nginx/백엔드 변경은 이 데모 구현에 포함하지 않는다.

## 체험 가능 범위

- 홈의 카테고리 전환, 전체 보기, 세션 내 관심 표시.
- 공통 검색: 제목·카테고리 부분 일치, 10개 초기 표시, 스크롤·버튼 추가 표시.
- 특정 가챠 ID 선택 후 예시 보유 매장과 선택 상품 요약 표시.
- 목록과 예시 지도 핀의 양방향 선택, 예시 영업 필터·거리 정렬.
- 매장 상세 갤러리, 사진 확대, 예시 보유 상품 목록.
- 교환 게시글의 카테고리·이름 검색, 오늘 교환 필터.
- 미구현 기능은 안내 창으로 표시하며 실제 신청·거래·업로드를 수행하지 않는다.

## 데이터와 보안

- 사진과 상품명은 기존 프로젝트의 공개 조회 API/S3 표본에서 준비한 정적 자산이다.
- 매장명·보유 관계·거리·가격·영업 상태·교환 게시글은 **체험용 예시**다.
- 지도는 실제 지도가 아닌 **예시 도식**이며, 위치 권한을 요청하지 않는다.
- DB API, AI API, 업로드 API는 데모 화면에서 호출하지 않는다.
- 관심 표시는 React 메모리에만 보관하며 새로고침 시 초기화된다.
- 기존 공통 HTML의 Google Fonts/PostHog 설정은 그대로 유지한다. 기존 분석 설정까지 비활성화했다고 해석하면 안 된다.
- 매장 사진은 WebP 변환 과정에서 EXIF/GPS 메타데이터를 제거했다.
- 실제 운영 API 계약이나 학습용 MSW를 이 데모 데이터에 맞춰 변경하지 않는다.

## 확인 시나리오

1. 홈에서 산리오 탭과 전체 보기, 관심 버튼을 확인한다.
2. 산리오 검색 시 12개 결과와 추가 표시, X/Escape 닫기를 확인한다.
3. 쿠로미 검색 후 가챠 선택 → 매장 목록 → 지도 핀 선택 → 매장 상세로 이동한다.
4. 상세 사진 확대 후 X/Escape로 닫고 브라우저 뒤로 가기·새로고침을 확인한다.
5. 교환 목록에서 피카츄 검색과 카테고리/오늘 필터를 확인한다.
6. 320/390/768/1024px에서 가로 넘침과 모바일 목록·지도 전환을 확인한다.
7. 데모 네트워크에 `/api/` 요청이 없고 루트 주소는 기존 앱인지 확인한다.
8. 일반 빌드의 소스맵에 `src/demo/` 모듈이 없는지 확인한다.

## 홍보 후

학습 작업은 원래 작업 디렉터리의 `feature/89-search-results`에서 그대로 이어 간다.
데모 전체를 학습 브랜치에 머지하거나 정식 검색 계약의 기준으로 삼지 않는다.

데모 제공을 종료하려면 DEV 워크플로우 명령을 `pnpm build`로 되돌리는 작은 PR을 만든다.
프리뷰 코드까지 철거할 때는 별도 제거 커밋으로 처리하며 기존 기록을 삭제하지 않는다.
