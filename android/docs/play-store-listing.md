# Google Play 최소 등록정보 초안

첫 비공개 테스트의 운영 빌드에는 지도, 매장 상세, 가챠 검색만 노출한다. 아직 노출하지 않는 거래·댓글·로그인·채팅·알림은 등록정보에서도 언급하지 않는다.

## 기본 등록정보

- 앱 이름: `가치가챠`
- 기본 언어: 한국어
- 앱 또는 게임: 앱
- 카테고리 제안: 쇼핑
- 광고 포함: 아니요
- 개인정보처리방침: `https://gachigacha.kro.kr/privacy`
- 앱 액세스: 모든 기능을 별도 로그인 없이 이용 가능
- 계정 삭제: 현재 앱에서는 계정을 만들거나 로그인할 수 없음
- 연락처 이메일: **Play Console에 공개 가능한 팀 이메일 확인 필요**

## 짧은 설명

```text
홍대 주변 가챠 매장을 지도에서 찾고, 원하는 가챠의 보유 매장을 검색해 보세요.
```

## 전체 설명

```text
가치가챠는 원하는 가챠와 가까운 매장을 한눈에 탐색할 수 있는 서비스입니다.

• 홍대 주변 가챠 매장을 지도에서 확인해요.
• 캡슐 마커와 매장 카드를 통해 매장 정보를 살펴봐요.
• 원하는 가챠를 검색하고 어느 매장에서 보유 중인지 확인해요.
• 매장 사진, 주소, 운영 정보와 보유 가챠를 확인해요.

첫 테스트 버전은 로그인 없이 누구나 이용할 수 있습니다.
```

## 그래픽 자산

- 앱 아이콘: `android/assets/play-store-icon.png`
- Feature graphic: `android/assets/play-feature-graphic.png` (1024×500 RGB PNG)
- 휴대전화 스크린샷: 최소 2장, 다음 3장을 권장
  1. 홍대 주변 매장 지도와 하단 매장 카드
  2. 가챠 키워드 검색 결과
  3. 매장 상세와 보유 가챠 목록

스크린샷에는 개발 앱 이름, Metro 화면, 에러 토스트, 개인정보, 기기 알림이 보이지 않게 한다. 운영 package를 내부 테스트로 설치한 화면을 사용한다.

## App content 응답 기준

- 로그인 또는 제한된 액세스: 없음
- 광고: 없음
- 사용자 생성 콘텐츠: 첫 운영 빌드에서는 거래글·댓글을 노출하지 않음
- 위치 권한: 요청하지 않음
- 외부 저장소 권한: 요청하지 않음
- 타깃 연령: 어린이를 대상으로 기획한 앱이 아니며 실제 팀 정책에 맞춰 13세 이상 구간 검토
- 콘텐츠 등급: 실제 매장·가챠 콘텐츠를 기준으로 설문에 사실대로 응답

## 데이터 보안 확인

현재 네이티브 앱은 로그인, 위치, 광고 SDK와 사용자 분석 SDK를 포함하지 않는다. 다만 Play Console의 데이터 보안 답변은 클라이언트 코드만으로 확정하지 않는다. 운영 API 및 인프라에서 IP 주소, 요청 로그나 기기 식별 정보를 수집·보관하는지 담당자에게 확인한 뒤 제출한다.

확인 전에는 `데이터를 수집하지 않음`으로 임의 제출하지 않는다.

