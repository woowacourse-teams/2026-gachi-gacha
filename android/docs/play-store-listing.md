# Google Play 등록정보 초안

> 마지막 점검: 2026-11-02

이 문서는 현재 운영 앱의 실제 기능을 기준으로 작성한다. Play Console에 그대로 복사하기 전에 연락처, 심사용 계정, Data safety와 광고 응답은 서비스·백엔드 담당자가 최종 확인한다.

## 기본 등록정보

- 앱 이름: `가치가챠`
- 기본 언어: 한국어
- 앱 또는 게임: 앱
- 카테고리 제안: 쇼핑
- 가격: 무료
- 개인정보처리방침: `https://gachigacha.kro.kr/privacy`
- 계정 삭제 URL: `https://gachigacha.kro.kr/account-deletion`
- 연락처 이메일: **Play Console에 공개 가능한 팀 이메일 확인 필요**
- 광고 포함: 네이버 쇼핑 커넥트 제휴 상품을 기준으로 `예` 권장. 최종 응답은 Play 정책 담당자가 확정
- 앱 액세스: 일부 기능은 로그인 필요

## 짧은 설명

```text
가챠 매장과 상품을 찾고, 이용자끼리 원하는 가챠를 교환해 보세요.
```

## 전체 설명

```text
가치가챠는 원하는 가챠와 가까운 매장을 찾고, 이용자끼리 가챠를 교환할 수 있는 서비스입니다.

• 지도에서 주변 가챠 매장과 보유 상품을 확인해요.
• 키워드와 카테고리로 원하는 가챠를 검색해요.
• 거래글과 댓글로 교환할 상품과 조건을 나눠요.
• 채팅으로 교환 일정과 장소를 조율해요.
• 새 댓글과 채팅 소식을 알림으로 받아요.
• 부적절한 콘텐츠와 사용자를 신고하거나 차단할 수 있어요.

일부 상품은 네이버 쇼핑 커넥트 제휴 링크로 제공되며, 구매가 발생하면 가치가챠가 수수료를 제공받을 수 있습니다.
```

과장된 안전 보장, 모든 매장의 실시간 재고 보장처럼 현재 서비스가 보증하지 않는 표현은 사용하지 않는다.

  3. 거래글 목록과 작성 버튼
  4. 거래글 상세, 댓글과 다른 교환 물품
  5. 채팅방 목록 또는 채팅 화면
  6. 마이페이지와 프로필 관리

스크린샷은 Play에서 설치한 운영 package로 다시 촬영한다. 개발 도메인, Metro 화면, 에러 토스트, 테스트 사용자 개인정보와 기기 알림이 보이지 않게 한다.

## 앱 액세스

지도와 검색은 로그인 없이 사용할 수 있지만 거래글 작성, 댓글, 채팅, 알림, 마이페이지와 계정 삭제는 로그인이 필요하다. 따라서 `앱의 전체 또는 일부 기능이 제한됨`으로 응답한다.

Play 심사자가 별도 승인이나 개인 휴대전화 인증 없이 반복해서 로그인할 수 있는 카카오 또는 네이버 심사용 계정을 제공한다.

심사 안내 예시:

```text
1. 앱 실행 후 우측 상단의 로그인을 선택합니다.
2. 제공한 소셜 계정으로 로그인합니다.
3. 상단 프로필에서 채팅, 알림, 마이페이지에 접근할 수 있습니다.
4. 마이페이지의 계정 관리 영역에서 로그아웃과 회원 탈퇴를 확인할 수 있습니다.
```

아이디와 비밀번호는 문서·저장소에 적지 않고 Play Console의 앱 액세스 입력란에만 등록한다. 2단계 인증, OTP, CAPTCHA 또는 기기 승인이 심사를 막지 않는지 사전에 확인한다.

## 계정 삭제

- 앱 내부: 마이페이지의 회원 탈퇴
- 외부 공개 경로: `https://gachigacha.kro.kr/account-deletion`

두 경로 모두 실제 계정과 관련 데이터를 삭제해야 한다. 백엔드 트랜잭션 수정 배포 후 소셜 재인증, 삭제 완료, 재로그인 불가, FCM 토큰 해제를 실기기에서 검증하기 전에는 프로덕션 심사에서 완료로 표시하지 않는다.

## 광고 및 제휴 표시

검색 화면에 네이버 쇼핑 커넥트 제휴 상품이 노출되고 구매 발생 시 수수료를 받을 수 있으므로 보수적으로 `광고 포함` 응답을 권장한다. 앱 내부 제휴 고지와 스토어 설명을 일치시킨다. 최종 분류가 애매하면 Play Console 정책 지원에서 확인한다.

## 타깃 연령과 콘텐츠 등급

- 어린이를 주 대상으로 설계한 앱이 아니다.
- 현재 개인정보처리방침과 가입 정책의 만 14세 이상 기준을 서비스 담당자와 일치시킨다.
- 거래글, 댓글, 채팅, 사진 등 사용자 생성 콘텐츠가 있음을 사실대로 응답한다.
- 신고, 차단, 운영자 검토 경로가 실제 동작하는지 확인한다.

## Data safety 확인표

Play 응답은 Android 네이티브 코드만 보지 않고 WebView의 웹 서비스, 서버, 분석·오류·푸시 도구까지 합쳐 판단한다.

| 데이터 범주 | 현재 처리 정황 | 확인할 목적/조건 |
| --- | --- | --- |
| 개인 정보 | 소셜 식별자, 닉네임, 프로필, 제공 시 이메일 | 계정 관리, 인증, 프로필 표시 |
| 사진 및 동영상 | 프로필·거래글·채팅 이미지 | 앱 기능 제공 |
| 메시지 | 채팅 내용, 댓글 | 교환 커뮤니케이션, 알림 |
| 앱 활동/사용자 콘텐츠 | 거래글, 검색·화면 활동, 신고·차단 | 기능 제공, 안전 운영, 분석 |
| 앱 정보 및 성능 | 오류 스택, 경로, 성능 정보 | Sentry 오류 진단 |
| 기기 또는 기타 ID | FCM 토큰, PostHog 익명 식별자 | 푸시, 분석 |
| 위치 | 사용자가 현재 위치를 요청할 때 브라우저 위치 사용 | 지도 이동. 서버·Kakao 전송 및 일시 처리 여부 확인 필요 |
| 기타 | IP, 브라우저·기기 정보, 세션 정보 | 보안, 운영 로그, 세션 유지 |

제출 전에 각 항목별로 다음을 확정한다.

1. 수집 여부와 제3자 공유 여부
2. 필수 또는 선택 여부
3. 앱 기능, 분석, 개발자 커뮤니케이션, 보안 등 사용 목적
4. 전송 중 암호화 여부
5. 계정 삭제 시 삭제 범위와 법적 보관 기간
6. PostHog, Sentry, Kakao, Naver, AWS 등 각 처리자의 역할이 Play의 `서비스 제공업체` 예외에 해당하는지

확인 전에는 `데이터를 수집하지 않음` 또는 `제3자와 공유하지 않음`으로 임의 제출하지 않는다.

## 권한 설명

| 권한 | 사용자에게 보이는 이유 |
| --- | --- |
| 대략적/정확한 위치 | 지도에서 현재 위치 주변을 확인할 때만 요청 |
| 알림(Android 13 이상) | 새 댓글과 채팅 푸시를 받을 때 요청 |

사용자가 위치나 알림 권한을 거절해도 지도 검색과 공개 탐색은 계속 사용할 수 있어야 한다.
