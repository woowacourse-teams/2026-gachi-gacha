# Android 1.0.0 실기기 통합 QA 체크리스트

이 문서는 `android` 브랜치의 운영 AAB를 만들기 전 DEV APK와 내부 테스트 빌드에서
반복할 최소 회귀 항목이다. 제품 화면은 최신 웹 `main`의 모바일 반응형 뷰와 비교한다.

## 기록 원칙

- 빌드 artifact 이름, commit SHA, package, versionName/versionCode를 함께 남긴다.
- 기기 모델, Android 버전, 3버튼/제스처 내비게이션을 기록한다.
- 성공 여부뿐 아니라 재현 순서와 화면 캡처를 남긴다.
- access/refresh token, FCM token, OAuth code, 개인 채팅 내용은 기록하지 않는다.

## 필수 기기 조합

- [ ] Samsung Galaxy 최신 Android, 3버튼 내비게이션
- [ ] Samsung Galaxy 최신 Android, 제스처 내비게이션
- [ ] Pixel 계열 또는 AOSP에 가까운 기기
- [ ] 작은 화면 또는 큰 글자 배율

## 인증과 계정

- [ ] Kakao 로그인 후 시작 화면으로 복귀한다.
- [ ] Naver 로그인 후 시작 화면으로 복귀한다.
- [ ] 앱 강제 종료·재실행 뒤 로그인 상태가 복구된다.
- [ ] access token 만료 시 중복 로그인 없이 갱신된다.
- [ ] 로그아웃 뒤 웹 세션, SecureStore, FCM token이 정리된다.
- [ ] 회원 탈퇴 뒤 이전 세션으로 다시 로그인되지 않는다.

## 핵심 사용자 흐름

- [ ] 거래 목록·검색·필터·상세·다른 교환글이 모바일 웹과 일치한다.
- [ ] 교환글 작성·수정·삭제와 사진·장소 선택이 정상 동작한다.
- [ ] 댓글 작성·읽음·신고·차단이 정상 동작한다.
- [ ] 지도 캡슐과 카드의 2단계 선택, 현재 위치, 재검색이 정상 동작한다.
- [ ] 검색 더보기, 쇼핑 커넥트와 외부 상품 링크가 정상 동작한다.
- [ ] 프로필 수정, 선호 지역, 내 글, 개인정보처리방침이 정상 동작한다.

## 채팅과 푸시

- [ ] 텍스트와 복수 이미지를 보내고 재접속 뒤에도 확인할 수 있다.
- [ ] 키보드를 열고 닫아도 입력창과 Android 시스템 영역이 겹치지 않는다.
- [ ] 백그라운드·화면 잠금·앱 종료 상태에서 댓글 푸시가 도착한다.
- [ ] 백그라운드·화면 잠금·앱 종료 상태에서 채팅 푸시가 도착한다.
- [ ] 푸시를 누르면 올바른 교환글 또는 채팅방 한 곳으로 이동한다.
- [ ] 알림 거부 상태에서도 앱의 댓글·채팅 기능은 동작한다.

## 오류와 복구

- [ ] 오프라인 첫 실행에서 재시도 화면이 표시되고 연결 후 복구된다.
- [ ] 느린 네트워크에서 중복 작성·중복 전송이 발생하지 않는다.
- [ ] 4xx/5xx 응답이 개발자 오류 원문 대신 사용자 안내로 표시된다.
- [ ] 지도·채팅 사용 중 background/foreground 복귀가 정상 동작한다.
- [ ] Android 뒤로가기는 WebView 이력 이동 후 루트에서 두 번 눌러 종료한다.

## 운영 빌드

- [ ] package가 `com.gachigacha.app`이다.
- [ ] 운영 API·OAuth callback·Firebase 프로젝트를 사용한다.
- [ ] 서명된 AAB의 versionName은 `1.0.0`, versionCode는 이전 업로드보다 크다.
- [ ] Play App Signing 인증서로 App Link와 Kakao Maps를 검증한다.
- [ ] 개인정보처리방침, 계정 삭제, 신고·차단, 심사용 로그인 안내를 제출한다.
